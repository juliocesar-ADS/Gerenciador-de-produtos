📦 Gerenciador de Estoque em Python
🧾 Sobre o projeto

Este é um projeto simples de gerenciador de estoque em Python, desenvolvido com foco em aprendizado.
O sistema funciona via terminal e permite ao usuário adicionar, remover e visualizar produtos de forma interativa.

⚙️ Funcionalidades
➕ Adicionar produtos ao estoque
❌ Remover produtos existentes
📋 Visualizar lista de produtos cadastrados
🚪 Encerrar o programa
💻 Como executar o projeto
1. Pré-requisitos
Ter o Python instalado (versão 3 ou superior)
2. Executar o código

No terminal, navegue até a pasta do projeto e rode:

python nome_do_arquivo.py
🖥️ Como usar

Ao iniciar o programa, você verá um menu com opções:

[1] ADICIONAR PRODUTO
[2] DELETAR PRODUTO
[3] VISUALIZAR PRODUTO
[4] SAIR
📌 Exemplo de uso:
- *[1]* Cadastra um novo produto informando nome e quantidade
- *[2]* Remove um produto pelo ID
- *[3]* Exibe todos os produtos cadastrados no banco
- *[4]* Encerra o programa

🧠 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar:

Estruturas de repetição (while, for)
Estruturas condicionais (if, else)
Listas em Python
Entrada e saída de dados no terminal
Conexão com banco de dados MySQL
Operações CRUD (Create, Read, Delete)
Organização de código em módulos
